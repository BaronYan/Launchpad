OJLaunch 隐私政策

最后更新：2026-11-07

OJLaunch 是一个 Windows 桌面应用启动器。我们**不收集、不上传、不共享**任何个人数据。

1. 应用会读取哪些信息

  • 开始菜单里的程序快捷方式（%ProgramData%\Microsoft\Windows\Start Menu\Programs 和 %APPDATA%\Microsoft\Windows\Start Menu\Programs），用于生成应用图标列表；
  • 这些快捷方式指向的程序图标，用于在面板中显示。

上述信息只在本机读取和显示，不会发送到任何服务器。

2. 应用会保存哪些信息

你在应用里做的个性化设置（图标顺序、文件夹、背景、快捷键等）保存在本机的 %LOCALAPPDATA%\Launchpad 目录下。卸载应用时，这些文件会随应用一起删除。

3. 网络

OJLaunch 不包含任何联网功能，不发送遥测、不检查更新、不做崩溃上报。

4. 第三方

本应用不包含第三方 SDK，不集成广告，不收集设备标识。

5. 儿童隐私

本应用不收集任何用户数据，因此也不涉及儿童数据的收集。

6. 联系方式

如有疑问，请通过商店页面的「支持」链接联系我们。

OJLaunch Privacy Policy

Last updated: 2026-11-07

OJLaunch is a desktop application launcher for Windows. We do not collect, upload, or share any personal data.

1. What the app reads

  • Program shortcuts in the Start Menu (%ProgramData%\Microsoft\Windows\Start Menu\Programs and %APPDATA%\Microsoft\Windows\Start Menu\Programs), used to build the icon list;
  • The icons of the programs those shortcuts point to, used to draw the launcher panel.

This information is read and displayed locally only. Nothing is sent anywhere.

2. What the app stores

Your personalization (icon order, folders, background, hotkey) is stored locally in %LOCALAPPDATA%\Launchpad. These files are removed when the app is uninstalled.

3. Network

OJLaunch has no network functionality. It sends no telemetry, performs no update checks, and reports no crashes.

4. Third parties

No third-party SDKs, no advertising, no device identifiers.

5. Children

The app collects no user data at all, so no children's data is collected.

6. Contact

For questions, use the support link on the Store listing page.
