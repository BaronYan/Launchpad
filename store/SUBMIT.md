# Partner Center 各分区怎么填（OJLaunch）

按左侧顺序从上到下填，**每一项都要点「保存」**，最后「提交认证」。

> 语言：先填简体中文，再点「添加语言」加 English (United States)。
> 文案在 `store\listing.md`，复制粘贴即可。

---

## 1. 商店列表（Store listing）

| 字段 | 填什么 | 从哪来 |
| --- | --- | --- |
| 产品名称 | `OJLaunch` | 已保留 |
| 简短描述 | 256 字符以内的一句话 | `store\listing.md` 的「简短描述」 |
| 详细描述 | 最多 10000 字符 | `store\listing.md` 的「详细描述」 |
| 产品功能 | 最多 20 条 | 「产品功能」那一段 |
| 搜索词 | 最多 7 个 | 「搜索词」 |
| 版权 | `Copyright © 2026 BaronYan` | |
| 截图 | **至少 1 张** | `store\screenshots\01-launchpad.png` 等 4 张，已做成 1920×1080 |
| 商店徽标 | 300×300 PNG | `store\logo-300.png` |
| 支持信息 | 邮箱 / 可选 URL | 你自己填 |

截图建议全传 4 张，顺序：主面板 → 文件夹 → 设置 → 搜索。

## 2. 属性（Properties）

| 字段 | 选什么 |
| --- | --- |
| 类别 | 主类别 **个性化（Personalization）**，次类别 **实用程序与工具** |
| 子类别 | 如果没有合适的，留空 |
| 系统要求 | **Windows 10 版本 19041.0 或更高**（我们自己声明的最小版本） |
| 架构 | x64 |
| 是否需要鼠标 | 是 |
| 是否需要键盘 | 建议「是」（有热键和搜索） |
| 是否需要触摸 | 否 |
| 是否支持辅助功能 | 否（没有专门的屏幕阅读器支持） |
| 是否使用 3D 显示 | 否 |
| 是否使用摄像头/麦克风/位置等 | 全部否（我们什么都不用） |
| 年龄分级 | 下一步填 |

> 「系统要求」里如果要求填 DirectX、内存等，写 **DirectX 9 以上不需要**、内存 **2 GB 即可**（因为程序本身很轻）。

## 3. 年龄分级（Age ratings）

会跳转 IARC 问卷，全部按实际情况选「否」：

| 问题类别 | 选项 |
| --- | --- |
| 暴力 / 血腥 | 否 |
| 性 / 裸露 | 否 |
| 语言 / 脏话 | 否 |
| 恐怖 / 惊悚 | 否 |
| 毒品 / 酒精 / 烟草 | 否 |
| 赌博 | 否 |
| 用户生成内容 / 社交 | 否 |
| 是否收集位置 / 分享个人信息 | 否 |
| 是否包含内购 / 广告 | 否 |
| 是否允许在线交互 | 否 |

结果一般会得到 **3+ / 适合所有年龄**。填完点「保存并生成分级」。

## 5. 提交选项（Submission options）

| 字段 | 填什么 |
| --- | --- |
| **隐私政策 URL** | **必填**。把 `store\privacy.html` 传到 GitHub Pages，填那个地址，例如 `https://你的用户名.github.io/ojlaunch/privacy.html` |
| 支持 URL | 可选，可填同一个站点或 GitHub 仓库 |
| 备注（给认证人员） | 见下方「认证备注」 |
| 出口管制 / 加密 | 选「否」（不使用加密，用的是系统自带 API） |
| 附加许可条款 | 留空（用标准应用许可证） |
| 是否包含广告 | 否 |
| 是否面向儿童 | 否 |

### 认证备注（建议原文）

```
无需登录或配置，启动后程序常驻系统托盘。

测试步骤：
1. 运行应用，任务栏不会出现窗口，托盘会出现图标（首次可能被 Win11 折叠进 ^，需要点 ^ 拖出来）。
2. 按 Ctrl + Alt + Space 打开全屏启动面板（若快捷键被占用会在 error.log 里记录并保留原快捷键）。
3. 左键点击托盘图标打开设置窗口，可改快捷键、背景、添加应用。
4. 设置窗口右上角 X 关闭，首次会询问「退出 / 收起到托盘」。

说明：
- 应用不联网、不收集数据，不请求任何敏感权限。
- 应用内没有测试账号，也没有付费功能。
```

## 6. 上传包这一步的常见报错

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| 无效的软件包标识名称 | 包里的 Identity Name 和产品不一致 | 改 `package\identity.json` 后重新生成 |
| 无效的软件包系列名称 | 同上（系列名由 Identity 派生） | 同上 |
| 使用了你未保留的显示名称 | DisplayName 不是已保留的名字 | 把 DisplayName 改成已保留的名称，或去保留新名字 |
| 包验证失败（架构） | 包是 x64，产品没勾对应架构 | 确认包是 x64，属性里选 x64 |
| 设备系列未勾选 | 没勾 Windows 10/11 Desktop | 在「包」页勾上 |
