## 中文（简体）

### 产品名称

OJLaunch
```

### 简短描述（≤ 256 字符）
```
像 macOS Launchpad 一样管理 Windows 应用：全屏图标网格、文件夹合并、模糊搜索、自定义背景与快捷键，一个热键随时唤出。
```

### 详细描述
```
OJLaunch 把 macOS Launchpad 的体验带到了 Windows。

按下 Ctrl + Alt + Space，当前桌面立刻变成一整屏应用图标——没有开始菜单的层层嵌套，也没有桌面上一堆快捷方式。

主要功能：

• 全屏应用网格
  自动扫描开始菜单里的所有程序，按你想要的顺序排列，滚轮即可翻页。

• 拖拽整理与文件夹
  把图标拖到另一个图标上，立刻合并成一个文件夹；文件夹里还能继续拖动排序；
  拖到文件夹外面松手，就把它移回桌面网格。

• 文件夹弹层
  点开文件夹是一个居中的圆角面板，双击文件夹名即可就地改名，拖到面板外自动收起。

• 全局搜索
  不只是顶层图标，文件夹里的程序也一起搜；不区分大小写，输入几个字母就能定位。

• 自定义外观
  背景支持纯色或自定义图片，透明度 0–100% 可调；图标支持 Ctrl + 滚轮缩放。

• 自定义快捷键
  点一下输入框，直接按下组合键即可录制新的全局热键。

• 手动添加应用
  没有出现在开始菜单里的程序，可以手动添加 exe 或快捷方式。

• 系统工具自动归类
  Windows 自带的管理工具会自动收进「系统工具」文件夹，不会和日常应用混在一起。

• 轻量、离线、无广告
  不联网、不收集任何数据，配置保存在本机。

提示：首次运行后，图标会出现在系统托盘；左键点托盘图标打开设置，热键打开启动面板。
```

## English (United States)

### Short description (≤ 256 chars)
```
A macOS-style Launchpad for Windows: full-screen icon grid, folders, fuzzy search, custom background and hotkey. One hotkey away.
```

### Description
```
OJLaunch brings the macOS Launchpad experience to Windows.

Press Ctrl + Alt + Space and your current desktop turns into a full screen of app icons —
no nested Start menu, no desktop cluttered with shortcuts.

Features:

• Full-screen app grid
  Scans all programs in your Start menu, arranges them the way you like, scroll to page.

• Drag to organize, drag to create folders
  Drop one icon onto another to merge them into a folder. Reorder inside a folder,
  drag out of the folder to move an app back to the grid.

• Folder popover
  A centered rounded panel with the folder's apps. Double-click the folder name to rename it
  in place, drag outside the panel to close.

• Global search
  Searches top-level icons and everything inside folders, case-insensitive.

• Custom look
  Solid color or your own image as background, opacity from 0 to 100%,
  Ctrl + mouse wheel to zoom the icon grid.

• Custom hotkey
  Click the field, press your combination, done.

• Add your own apps
  Add any exe or shortcut that does not appear in the Start menu.

• Built-in Windows tools grouped automatically
  Administrative tools go into a "System Tools" folder instead of mixing with your daily apps.

• Lightweight, offline, no ads
  No network access, no data collection, settings stay on your machine.
```

### Features
```
Full-screen launcher grid, one hotkey away
Drag icons together to create folders
Reorder inside folders, drag out to remove
Rename folders in place with a double-click
Search covers both top-level and folder apps
Case-insensitive fuzzy matching
Solid color or custom image background
Background opacity from 0 to 100%
Ctrl + mouse wheel to zoom icons
Custom global hotkey
Add any exe or shortcut manually
Windows admin tools grouped into System Tools
Local settings, no network, no ads
